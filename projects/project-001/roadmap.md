# Project 001 Roadmap

This roadmap represents the current plan and will change as the project develops.

## Phase 0 — Hypothesis

- Define the problem
- Define the intended audience
- Define what makes the project worth following
- Establish principles and boundaries
- Determine how success will be measured

## Phase 1 — Public Design

- Develop the character concept
- Define personality and communication rules
- Design the memory model
- Draft the transparency dashboard
- Gather public feedback
- Document major decisions

## Phase 2 — Private Prototype

- Build the first agent workflow
- Create structured memory
- Generate draft posts and replies
- Add a human approval queue
- Test consistency and safety
- Record rejected outputs and lessons

## Phase 3 — Public Prototype

- Launch the character publicly
- Publish approved content
- Begin limited community interaction
- Display selected activity through the dashboard
- Measure engagement and consistency

## Phase 4 — Limited Autonomy

- Automate low-risk actions
- Expand memory and community awareness
- Introduce controlled experiments
- Maintain emergency pause and human override
- Publish performance and failure reports

## Phase 5 — Ecosystem

- Explore multiple agents or characters
- Develop reusable infrastructure
- Consider community tools and integrations
- Evaluate whether a token adds genuine utility

## Current Milestone

Complete the Project 001 definition before beginning software development.
