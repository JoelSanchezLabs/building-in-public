# Projects

JoelSanchezLabs is a collection of AI experiments built openly and documented from the beginning.

Each project will have its own purpose, roadmap, architecture, decisions, experiments, and build history.

Projects may succeed, fail, or evolve into something completely different.

The objective is not to pretend every idea is correct.

The objective is to make the process visible and learn from the results.
